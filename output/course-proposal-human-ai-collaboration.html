人机协同课程 · 从分析到落地

基于京东课程模式分析，设计适合初学者的渐进式人机协同课程。每步有交互、有产出、有反馈，让学员"学了就能试，试了就能用"。

01 / 京东课程完整分析

走读 3 条路径 · 提取 6 个核心设计要素

完整走读了 AI 通识 10 步路径、前端全栈 10 步路径、以及课程 01-03 的内部页面。以下是核心发现。

已分析内容
AI 通识路径：10 步课序 + 课程 01（大模型通识，7 章 3 交互组件） + 课程 02（认识 Token，3 章 1 交互组件）
前端全栈路径：10 步课序 + 课程 01（HTML 核心知识，~15 章，代码密集型）
平台全局：范式框架、角色演进、6 条学习路径设计、领航/蝶变双轨
要素 01 · 课序设计
步进式 + 混合编排 + 自动解锁
每路径 10 步，课程 × 7 + 实战 × 2 + 测验 × 1。每节点标注 STEP、类型、时长、状态（已完成/进行中/未解锁）。完成当前节点自动解锁下一项，形成"学完即走、走完即开"的闭环。实战节点出现在每 1-2 门课后。
要素 02 · 章节结构
概念 → 交互 → 洞察 三段式
每章 = 概念阐述（简单直白）→ 交互组件（动手试）→ 关键洞察（一句话记住）。编号层级 1.→2.→2.1→2.2 清晰。每章开头有标题，正文图文混排。
要素 03 · 交互组件
4 类组件降低认知门槛
① 滑块+实时反馈 — 抽象概念变可调参数（Temperature/成本）② 单选+动态输出 — 切换场景看结果变化 ③ 分步演示 — 复杂过程拆成 4 步 ④ 实时图表 — 数据变化可视化。每个组件有图标+标题+副标题区。
要素 04 · 信息呈现
5 种信息框 + 对比表 + ❌✅
蓝色 info（重要提示/公式）、红色 warning（成本陷阱）、金色 highlight（优化原则）、深色 insight（核心直觉）、绿色 success（关键发现）。对比表格横向滚动，❌✅ 优劣对比直观。
要素 05 · 侧边栏导航
目录自动高亮 + 进度暗示
每课右侧固定侧边栏显示本页目录，滚动时自动高亮当前章节。侧边栏底部有提示"完成本课后 X 会自动解锁"，制造期待感。
要素 06 · 状态反馈
无处不在的进度感知
学习路径页：顶部进度摘要（百分比 + 已学/总节点 + 剩余分钟）+ 当前节点 + 继续学习按钮。课程页：顶栏路径标明当前位置，底部"完成当前课程"按钮。

京东课程"好效果"的 5 个秘诀
1. 极短课时 — 每课 10-15 分钟，不产生学习疲劳。一次学一个概念，配一个交互。
2. 抽象→具象 — 每个概念都配一个交互组件。理解了原理马上动手调参数，看到结果变化。
3. 零认知负担 — 没有"先修要求"，不铺垫理论基础。直接从日常场景切入（"你有没有遇到过..."）。
4. 即时反馈 — 滑块一拖、按钮一点，结果立刻显示。学员不需要思考"我学得对不对"。
5. 进度透明明 — 任何时候都知道自己在哪、还剩多少、下一步是什么。学习路径清晰可预期。

关键设计原则
① 每课时不超过 20 分钟 — 京东验证 10-15 分钟最有效。
② 每课时至少一个交互或产出 — 不能只有"读"，必须有"做"。
③ 先实战再理论 — 先给学员一个工具（3A 分诊器），他们用了产生兴趣，再讲背后的逻辑。
④ 产出一致性 — 每步产出都是"自己的"（自己的阶段定位、自己的 AGENTS.md、自己的判断档案），不是通用案例。
03 / 交互组件设计

7 个交互组件 · 覆盖 10 步全部课程

每个组件解决一个特定的认知难点。全部用纯 HTML/CSS/JS 实现，零外部依赖。初级组件（滑块/勾选/单选）+ 中级组件（步骤演示/对比）+ 高级组件（可视化图表）。

①
协同阶段自测 · 勾选式评估器
用于 Step 01 · 复杂度：初级 · 开发量：~40 行 JS
作用
学员勾选 6-8 个能力条目，系统自动判定所属阶段（S1-S4）。零门槛，30 秒完成。结果带阶段描述和推荐学习路径。
交互逻辑
checkbox 勾选 → 按阶段分组计分 → 取最高分阶段 → 展示定位结果（徽章+描述+推荐）→ 可选保存到 localStorage
<!-- 核心逻辑 --> function calcStage(checks) { const scores = [0,0,0,0]; // S1-S4 checks.forEach(c => { if(c.checked) scores[c.dataset.tier-1]++; }); const max = Math.max(...scores); const stage = scores.lastIndexOf(max) + 1; return { stage, label: ['入门','工具化','判断力','分身化'][stage-1] }; }
②
3A 分诊器 · 三滑块实时推荐
用于 Step 02 · 复杂度：初级 · 开发量：~50 行 JS
作用
仿京东 Token 成本计算器。3 个滑块（确定性/可逆性/跨度）→ 实时计算 → 推荐 Auto/Augment/Agent。右侧同步显示分工建议。
交互逻辑
range slider input → 判定规则（不可逆则增强、确定+可逆则看跨度等）→ 更新模式名/颜色/分工卡片 → 平滑过渡动画
// 判定规则（验证过的逻辑） function triage(certainty, reversibility, span) { if (reversibility < 35) return 'augmentation'; if (certainty > 65 && reversibility > 50) return span > 60 ? 'agent' : 'automation'; if (span > 65 && certainty > 45 && reversibility > 45) return 'agent'; if (certainty > 60) return 'automation'; return 'augmentation'; }
③
实战任务卡片 · 拖拽/分拣式练习
用于实战 Step ✦ · 复杂度：中级 · 开发量：~80 行 JS
作用
给学员 5 个真实任务场景卡片，拖到对应的 3A 抽屉里。系统自动判定对错并给出解释。之后学员可以输入自己的任务做分类。
交互逻辑
drag & drop 或点击分类 → 比对正确答案 → 显示正确/错误及原因 → 全部完成后显示得分 → 切换到"我的任务"输入模式

04 / 课程详细设计

Step 01 和 02 的完整落地实现

以下展示两门核心课程的章节结构、每章的交互形式、学习者体验流程和技术实现要点。

STEP 01 · 课程
人机协同全景认知
⏱ 15 分钟 · 2 个交互
第一章 · 核心命题
一句话说清什么是人机协同。从"让AI帮你做"到"让AI替你做好"，核心是判断力的传递。

呈现：一句话引语 + 数据 callout（40 万次对话验证）
第二章 · 四层本质模型
用一张 4×2 对比表展示四层分工（执行/判断/知识/进化）。每层三句话：核心问题 + 人做什么 + AI做什么。

呈现：横向滚动对比表 + 洞察 callout
🎮 第三章 · 交互自测
6 个 checkbox 勾选你的能力。系统自动判定你在 S1-S4 哪个阶段。结果带阶段描述和推荐路径。

交互组件：① 协同阶段自测
第四章 · 数据说了什么
5 个关键数据点展示表。每个数据点 = 数据 + 来源 + 启示。让学员建立"人机协同有数据支撑"的认知。

呈现：3 列表格 + 核心发现 callout
STEP 02 · 课程
3A 分诊法：30 秒决定怎么分
⏱ 15 分钟 · 1 个交互
第一章 · 三抽屉模型
三个抽屉 = 三种协同模式。一张 3×4 对比表展示每种模式：AI角色、人角色、典型场景。

呈现：对比表 + 核心原则 callout
第二章 · 三维度判定
三个维度决定任务怎么分：确定性、可逆性、跨度。每个维度用一句话+一个标尺解释。

呈现：三行文字 + 判定逻辑 callout
🎮 第三章 · 交互分诊
左侧：任务描述输入框 + 3 个维度滑块。右侧：实时推荐的协同模式 + 分工建议（人做什么 + AI做什么）。

交互组件：② 3A 分诊器
学员体验流程：输入自己的任务 → 拖动 3 个滑块 → 看到推荐结果 → 验证是否合理 → 调整滑块观察变化 → 理解判定逻辑
技术实现方案
纯静态 HTML + 无依赖 JS
前端技术栈
• 纯 HTML/CSS/JS，零依赖
• 所有交互组件原生实现
• localStorage 存学员进度+产出
• 响应式设计（移动端适配）
组件开发顺序
• Phase 1：自测评估器 → 3A 分诊器 → 模板生成器
• Phase 2：任务分拣 → 3 步提取器 → 闭环流程图
• Phase 3：协同沙盘 → 综合测验
内容管理
• 所有课程内容写在 HTML 中
• 交互数据用 JSON 对象管理
• 学员产出存 localStorage
• 无需后端，可部署到任何静态服务器
