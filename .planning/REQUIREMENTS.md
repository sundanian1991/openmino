## 四、范式一 · Copilot 个人提效

### Step 01 · 课程：你现在的 AI 协同阶段

- [ ] REQ-30: **概念** — 四阶模型（S1 入门/S2 工具化/S3 判断力/S4 分身化），每阶一句话定义
- [ ] REQ-31: **案例** — 真实数据：大多数学习者卡在 S1（入门阶段），管理类职业验证成功率（37%）反超软件工程师（34%）（来源：Anthropic 40万次对话研究，2026.6）
- [ ] REQ-32: **交互① 成熟度自测** — 12 道勾选题（4 阶段 × 3 题），勾选后自动判定阶段
  - 交互模式：京东勾选式评估器
  - 输出：阶段徽章 + 阶段解释 + 下一步建议 + 推荐进入节点
  - 规则：S1 ≥ 2 题勾选即具备 → S2 ≥ 2 → S3 ≥ 2 → S4 ≥ 2，取最高满足阶段
- [ ] REQ-33: **产出** — 学员的阶段定位报告（可保存到 localStorage）

### Step 02 · 实战：3A 分诊法

- [ ] REQ-40: **概念** — 三抽屉模型（Automation / Augmentation / Agent），每种一句话+典型场景
- [ ] REQ-41: **三维度判定** — 确定性（模糊→明确）、可逆性（不可撤→可回滚）、跨度（单步→多步）
- [ ] REQ-42: **对比表** — 3×4 表：模式 × AI角色/人角色/典型场景/验收方式
- [ ] REQ-43: **交互② 3A 分诊器** — 任务描述输入框 + 3 个滑块 + 实时推荐
  - 交互模式：仿京东 Token 成本计算器（多滑块联动）
  - **滑块规格**：range 0-100，分值越高代表该维度越突出
    - 确定性滑块：0=完全模糊 / 100=完全明确
    - 可逆性滑块：0=不可撤回 / 100=可随时回滚
    - 跨度滑块：0=单步即可 / 100=需多步长流程
  - 输出：推荐模式 + 理由 + 人做什么 + AI 做什么 + 验收标准 + 风险提醒
  - 规则：可逆性 ≤ 30 → 高风险提醒；确定性 ≤ 35 → 提示先补充标准
  - 存储：实时计算，结果可复制为 Markdown，草稿存入 localStorage（避免刷新丢失）
- [ ] REQ-44: **产出** — 任务分诊结果 Markdown（可复制）

### Step 03 · 课程：给 AI 写规则

- [ ] REQ-50: **概念** — AGENTS.md 是给 AI 看的说明文件，不是给人看的 README
- [ ] REQ-51: **五条黄金法则** — 具象优先、机器友好格式、单一职责、禁令清单最重要、正误示例
- [ ] REQ-52: **交互③ 操作手册生成器** — 表单填写 → 实时 Markdown 预览
  - 交互模式：仿 Prompt 五件套组装实验室（模块化拼装）
  - 字段：任务名称/适用场景/输出格式/必须遵守/禁止事项/正确示例/错误示例/验收标准
  - 约束：至少 3 条 Never，禁止空泛词
- [ ] REQ-53: **产出** — 学员自己的 AI 操作手册草稿（可复制、可保存）

### Step 04 · 实战：高频任务小工具化

- [ ] REQ-60: **概念** — 每次从零写 Prompt 是浪费，把高频任务做成模板
- [ ] REQ-61: **预设场景** — 周报生成 / 会议纪要 / 竞品分析 / PRD 检查 / 数据解读 / 邮件润色
- [ ] REQ-62: **交互④ 场景模板切换** — 点标签切换场景 → 显示模板 + 填写区
  - 交互模式：仿 Prompt 场景模板切换
  - 流程：选场景 → 填你的内容 → 出结果 → 复制模板
- [ ] REQ-63: **产出** — 3 个自己高频任务的模板
