## 逐课方案

### Step 01 · 你现在的 AI 协同阶段

| 组件 | 类型 | 交互形式 | 复杂度 |
|------|------|---------|--------|
| ① 成熟度自测 | ✅ 已有 | 12 checkbox → 阶段判定 | ⭐ |
| ② **知识点小测验** | ➕ 新增 | 3 道对错题，判断你了解 AI 协同吗 | ⭐ |

**② 知识点小测验**：课程开始前 3 道快速判断题，让学员进入学习状态。
```
例：人机协同的本质是"让 AI 替我做所有事"？ → 错
    判断说得越清楚，AI 能接走的任务越多？ → 对
```
形式：3 个 radio 对错选择 → 提交 → 显示正确率 + 一句话引导。

---

### Step 02 · 3A 分诊法

| 组件 | 类型 | 交互形式 | 复杂度 |
|------|------|---------|--------|
| ② 3A 分诊器 | ✅ 已有 | 3 滑块 + 实时推荐 | ⭐ |
| ③ **任务匹配练习** | ➕ 新增 | 3 个任务 → 拖选到对应抽屉 | ⭐⭐ |

**③ 任务匹配练习**：给 3 个日常任务卡片，学员点选（或拖拽）到 Automation / Augmentation / Agent 三个区域。选完后显示正确答案 + 解释。
```
卡片 1：「把上个月的招聘数据整理成报表」→ Automation
卡片 2：「评估两个供应商方案并给推荐」→ Augmentation  
卡片 3：「完整调研某个竞品并输出报告」→ Agent
```

---

### Step 03 · 给 AI 写规则

| 组件 | 类型 | 交互形式 | 复杂度 |
|------|------|---------|--------|
| ③ 手册生成器 | ✅ 已有 | 8 字段表单 → Markdown | ⭐ |
| ④ **规则对比演示** | ➕ 新增 | 点切换看 好规则 vs 差规则 | ⭐ |

**④ 规则对比演示：** 点标签切换，同一任务的好/差规则对比。
```
差规则：「写一份高质量的报告」
好规则：「报告包含三部分：摘要(100字)、数据(表格)、结论(3条)」
```
学员点"差规则"看为什么不好，点"好规则"看具体怎么改进。

### Step 08 · AI 项目管理法（新增 2 个）

**当前 0 个交互，这是最大缺口。**

| 组件 | 类型 | 交互形式 | 复杂度 |
|------|------|---------|--------|
| **⑧-1 项目启动器** | ➕ 新增 | 引导表单 → 生成 PROJ.md | ⭐ |
| **⑧-2 里程碑规划器** | ➕ 新增 | 拖滑块设里程碑 → 自动生成 PLAN.md | ⭐⭐ |

**⑧-1 项目启动器**：3 步引导。
```
Step 1：项目叫什么？（输入名称）
Step 2：目标是什么？（写一句话）
Step 3：不做什么？（选 3 个复选框：不加功能/不改后端/不接第三方）
→ 生成 PROJ.md
```

**⑧-2 里程碑规划器**：设 2-4 个里程碑，拖动滑块分配时间。
```
M1：骨架（3天）───●──────
M2：功能（5天）──────●────
M3：测试（2天）────────●─
→ 生成 PLAN.md 草稿
```

### Step 10 · 构建你的数字分身（新增 2 个）

**当前 0 个交互，其次缺口。**

| 组件 | 类型 | 交互形式 | 复杂度 |
|------|------|---------|--------|
| **⑩-1 三组件检查器** | ➕ 新增 | 3 个 checkbox 组，看你差什么 | ⭐ |
| **⑩-2 递进模拟器** | ➕ 新增 | 点按钮模拟"第一次→第二次→第N次" | ⭐ |

**⑩-1 三组件检查器**：
```
你的数字分身还缺什么？
□ 知识库（文档/规范/历史数据）
□ 技能包（AGENTS.md / Prompt 模板）
□ 判断档案（决策标准记录）
→ 显示：你缺 XX，建议优先补齐
```

**⑩-2 递进模拟器**：点按钮推进，看数字分身的进化过程。
```
[第一次] → 你做一遍，记录判断标准
[第二次] → AI 按你的标准执行，你微调
[第N次]  → AI 独立完成，你只看异常
```
每次点击展示对应的具体案例（如周报场景的变化）。

```
Phase 1（优先做缺口最大的）:
  Step 08 +2（项目启动器 + 里程碑规划器）
  Step 10 +2（三组件检查器 + 递进模拟器）

Phase 2（补充轻量交互）:
  Step 01 +1（知识点测验）
  Step 02 +1（任务匹配练习）
  Step 03 +1（规则对比演示）
  Step 05 +1（流程图点击）
```

## 总体原则
- 每个新增组件不超过 60 行 JS
- 不做拖拽（兼容性问题），用"点选"代替
- 所有交互用完即走，不留未完成态压力
- 组件放在对应章节末尾，"学完试试"
