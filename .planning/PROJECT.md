# PROJECT.md

> 人机协同实战课 · Copilot → Agentic → AI Native

## What This Is
一套面向京东内部非技术岗（产品/运营/HR/采购等）的人机协同实战课程。以三范式为能力进阶主线（Copilot 个人提效 → Agentic 流程协同 → AI Native 全栈闭环），从简单到复杂递进，每个节点有交互、有产出、可反复学习参考。

## Core Value
让学习者从"会问 AI"升级为"会设计 AI 工作流、会分工、会验收、会沉淀自己的判断标准"。

## Measurable Goals
完成课程的学习者应能：
1. 用 3A 框架分解任意日常工作任务，准确判断应使用 Automation / Augmentation / Agent
2. 为自己的高频工作写一份 AI 操作手册（含规则、禁令、验收标准）
3. 用三层协同框架（L1/L2/L3）描述一个长周期项目的人机分工
4. 沉淀至少 3 条个人判断档案，可供 AI 复用
5. 交付一份完整的"我的人机协同 SOP v1"（10 字段结构化文档）

## Users
> 以下 7 岗位基于 160 名同事 / 11 模块 / 1249 条真实工作记录，差异化路径详见 ROLE_PATHS.md

- 产品运营岗 — 数据分析、会议沟通、资料收集、文档处理、项目管理
- 监管风控岗 — 合规管理、风险评估、数据分析
- 客户运营岗 — 客户服务、资料收集、数据分析、文档处理
- 销售运营岗 — 数据分析、策略制定、文档处理、项目管理
- 投资研究岗 — 数据分析、策略制定、资料收集、风险评估（样本量小，路径为初步建议）
- 数据分析岗 — 数据分析、技术实施、资料收集（样本量小，路径为初步建议）
- 审核顾问岗 — 资料收集、合规管理、文档处理、客户服务（样本量小，路径为初步建议）

## Design Principles
1. **交互驱动理解** — 每个核心概念配至少一个交互组件，不是"读了就懂"而是"动手才懂"
2. **每节点有产出** — 没有产物的章节不进入主路径
3. **即学即用** — 每节课产出都是学员自己的（自己的自测结果、自己的任务分诊、自己的操作手册）
4. **可反复参考** — 所有页面在学完后仍可回到对应节点查阅和复用
5. **案例为重** — 三层协同案例做成交互式案例实验室，便于反复学习参考

## Constraints
- 技术：纯静态 HTML/CSS/JS，零构建工具 · 零后端 · 允许 CDN
- 数据：localStorage 存进度和产出
- 部署：可放到任何静态服务器（京东内部可直接部署）
- 风格：Nothing Light（暖白底 + 红 accent + Space Grotesk/Doto/Space Mono）

## Out of Scope
- 后端服务 — 纯静态，不接 API
- 用户登录 — 不接学习平台
- AI API 调用 — 所有交互纯前端模拟
- 视频录制 — 纯交互式页面
