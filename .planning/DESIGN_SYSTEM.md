# Nothing Light Design System

> 人机协同实战课 · 设计系统
> 定义"长什么样、为什么这么设计、什么时候用什么"——不涉及具体代码实现。

---

## 一、品牌 DNA

### 课程名
人机协同实战课 · Copilot → Agentic → AI Native

### 设计人格
- **调性**：干净、克制、专业、有温度
- **关键词**：暖白、单色、一个红色 break point、足够的留白
- **避免**：科技感蓝紫渐变、圆角卡片、拟物阴影、过度动效
- **灵感**：Nothing 品牌的极简主义、瑞士平面设计的网格系统、学术出版物的排版秩序

### 设计语言一句话
"温暖的白纸上，只有一种红色值得你注意。"

## 二、设计 Token

### 2.1 色彩体系

#### 主色盘
| Token | 色值 | 用途 |
|-------|------|------|
| `--bg` | #F5F5F5 | 页面背景，暖白基调 |
| `--surface` | #FFFFFF | 卡片、面板、内容区 |
| `--surface-raised` | #F0F0F0 | 浅灰底色（表格头、次要背景） |

#### 文字色盘
| Token | 色值 | 用途 |
|-------|------|------|
| `--text-display` | #000000 | 标题、品牌文字 |
| `--text-primary` | #1A1A1A | 正文、重要信息 |
| `--text-secondary` | #666666 | 辅助说明、次要信息 |
| `--text-disabled` | #999999 | 禁用、未解锁、提示文字 |

#### 边框色盘
| Token | 色值 | 用途 |
|-------|------|------|
| `--border` | #E8E8E8 | 默认边框，极淡灰色 |
| `--border-visible` | #CCCCCC | 需要更明显的边框（输入框、表格） |

#### 功能色盘
| Token | 色值 | 用途 |
|-------|------|------|
| `--accent` | #D71921 | **唯一的强调色**。只用于：当前状态、完成按钮、重要警示、模式标识 |
| `--accent-subtle` | rgba(215,25,33,0.07) | 红色信息框的背景 |
| `--success` | #4A9E5C | 完成状态、已验证 |
| `--blue` | #007AFF | Automation 模式、info 信息框 |
| `--blue-subtle` | rgba(0,122,255,0.07) | 蓝色信息框背景 |
| `--purple` | #8B7CF6 | Agent 模式 |
| `--gold` | #D4A843 | 提示框、优化建议 |

#### 色彩使用原则
- 整个界面**只有一种强调色**（红色 #D71921）。其他颜色（蓝/绿/紫/金）只在特定语义场景使用
- 不要同时用红色做强调和其他颜色的强调——红色是唯一的"注意力锚点"
- 功能色（蓝/紫/绿/金）只在信息框和模式标签中出现，不作为界面主色

### 2.2 字体体系

| 角色 | 字体 | 字重 | 用途 |
|------|------|------|------|
| 展示字体 | Doto | 400, 500, 600, 700 | 大标题数字、统计数值、装饰性元素 |
| 正文字体 | Space Grotesk | 300, 400, 500, 600, 700 | 正文、标题、按钮、表单 |
| 等宽字体 | Space Mono | 400, 500, 700 | 代码、标签、标注、数据、mono 元素 |

#### 字号阶梯
| Token | 大小 | 行高 | 用途 |
|-------|------|------|------|
| --display-xxl | 96px | 1 | Hero 背景装饰字 |
| --display-xl | 72px | 1 | 超大题头（极少用） |
| --display-lg | 48px | 1.05 | 页面大标题 |
| --display-md | 36px | 1.1 | 区块标题 |
| --heading | 24px | 1.2 | 章节标题 |
| --subheading | 18px | 1.3 | 卡片标题 |
| --body | 16px | 1.5 | 正文 |
| --body-sm | 14px | 1.6 | 小字正文 |
| --caption | 12px | 1.5 | 标注、辅助文字 |
| --label | 11px | 1.4 | 标签、mono 标注 |

### 2.3 间距体系

以 4px 为基数的递增序列：
```
2xs: 4px   — 极小间距（图标和文字之间）
xs:  8px   — 紧凑间距（标签内、inline 元素）
sm:  16px  — 常规间距（卡片内、表单项之间）
md:  24px  — 区块间距（标题和内容之间）
lg:  32px  — 章节间距（不同章节之间）
xl:  48px  — 大区块间距
2xl: 64px  — 页面模块间距
3xl: 96px  — 页面大区块间距
4xl: 128px — Hero 区域上下间距
```

#### 间距使用原则
- 垂直方向用倍数增长（16→24→32→48→64），保持节奏感
- 卡片内 padding 统一用 --space-xl（32px）
- 章节间用 --space-2xl（48px）
- 不要用奇数间距

## 三、组件设计

### 3.1 导航栏 (Nav)

| 属性 | 值 |
|------|-----|
| 位置 | 固定顶部，z-index 100 |
| 高度 | 56px |
| 背景 | rgba(245,245,245,0.92)，backdrop-filter: blur(12px) |
| 底部分割 | 1px solid var(--border) |
| 左侧 | 品牌名（mono, 12px, 700, uppercase） |
| 右侧 | 导航链接（mono, 11px, uppercase） |
| 激活态 | 红色 2px 下边框 |
| 交互 | hover 变为黑色文字 |

### 3.2 阅读进度条

| 属性 | 值 |
|------|-----|
| 位置 | 紧贴 nav 下方，全宽 |
| 高度 | 3px |
| 颜色 | var(--accent) |
| 动效 | width 变化，cubic-bezier(0.4, 0, 0.2, 1), 0.3s |
| 初始 | width: 0% |

### 3.3 按钮系统

#### 主要按钮 (.btn-primary)
- 背景：var(--text-display)（黑色）
- 文字：白色
- 边框：var(--text-display)
- Hover：背景变为 var(--accent)，边框变为 var(--accent)
- Padding：12px 28px
- 字号：14px，500 weight

#### 次要按钮 (.btn)
- 背景：var(--surface)（白色）
- 文字：var(--text-primary)
- 边框：1px solid var(--border-visible)
- Hover：背景变为 var(--text-display)，文字变为白色

#### 复制按钮
- Mono 字体，11px，uppercase
- 带图标或纯文字
- 点击后文字变为"已复制 ✓"，短暂动画反馈

### 3.4 信息框系统

5 种信息框，统一结构：左边框 + 背景色 + 标签 + 正文：

| 类型 | 左边框色 | 背景 | 标签色 | 用途 |
|------|---------|------|--------|------|
| 默认 (callout) | var(--accent) 红 | var(--accent-subtle) | 红色 | 核心洞察、重要提醒 |
| info | var(--blue) 蓝 | var(--blue-subtle) | 蓝色 | 补充信息、数据来源 |
| success | var(--success) 绿 | rgba(74,158,92,0.07) | 绿色 | 成功、已完成提示 |
| gold | var(--gold) 金 | rgba(212,168,67,0.1) | 金色 | 优化建议、最佳实践 |
| dark（深色背景） | #FF6B6B | var(--text-display) | #FF6B6B | 深色区特殊展示 |

#### 信息框结构
```
┌─────────────────────────────────────────┐
│ 标签（mono, 9px, uppercase, 彩色）       │
│ 正文（13px, 次要色，行高 1.7）          │
└─────────────────────────────────────────┘
```

### 3.5 对比表

- 全宽，带横向滚动（移动端）
- 表头：mono, 10px, uppercase, 灰色
- 表体：13px, 次要色
- 第一列：primary 色，500 weight
- 行 hover：浅灰背景
- 底部分割线：1px var(--border)

### 3.6 侧边栏目录

| 属性 | 值 |
|------|-----|
| 位置 | 右侧固定，top: 80px |
| 宽度 | 260px |
| 标题 | mono, 10px, uppercase |
| 链接 | 12px, 次要色，左侧 2px 透明边框 |
| 激活态 | 红色左侧边框 + 红色文字 |
| 交互 | hover 变为 primary 色 |

### 3.7 节点状态标识

三种状态，视觉区分明显：

| 状态 | 视觉 | 颜色 |
|------|------|------|
| 未解锁 | 锁图标 + 灰色文字 + 低透明度 | var(--text-disabled) |
| 进行中 | 红色高亮 + 红色左侧边框（列表项） | var(--accent) |
| 已完成 | 绿色对勾 + 灰色文字 + 略低透明度 | var(--success) |

### 3.8 交互组件外壳

所有交互组件遵循同一外观：

- 背景：var(--surface)（白色卡片）
- 边框：1px solid var(--border)
- Padding：32px
- 顶部有标题栏：图标 + 名称（14px, 600） + 副标题（mono, 10px, 灰色）在右侧
- 内部组件间距：24px（--space-lg）

## 五、交互设计原则

### 5.1 反馈原则
- **即时**：滑块拖动、勾选点击、按钮按下，100ms 内给出视觉反馈
- **明确**：状态变更必须伴随视觉变化（颜色/位置/大小）
- **可逆**：所有操作可撤销或可修改

### 5.2 动效原则
- 只用在有意义的时机：状态切换、内容变化、完成确认
- 过渡时间 150-300ms
- 缓动函数统一用 cubic-bezier(0.4, 0, 0.2, 1)
- 禁用：闪烁、旋转、弹跳等装饰性动效

### 5.3 无障碍原则
- 所有交互元素支持键盘操作（Tab/Enter/Space）
- 颜色对比度满足 WCAG AA 标准
- 不单独依赖颜色传递信息（配合图标/文字）

## 六、组件使用决策

### 什么时候用什么组件

| 你需要 | 用这个 |
|--------|--------|
| 强调一个关键发现 | 红色 callout |
| 补充背景信息 | blue info callout |
| 展示成功/完成状态 | green success callout |
| 给出最佳实践建议 | gold callout |
| 让用户自己评估 | 勾选式自测组件 |
| 让用户调整参数 | 滑块式分诊组件 |
| 让用户填空产出 | 表单 → Markdown 组件 |
| 展示选项让用户选 | 标签切换组件 |
| 分步引导填写 | Step N/M 推进组件 |
| 展示数据对比 | 横向滚动对比表 |
| 展示代码/产物 | 代码块 + 复制按钮 |

### 不要做什么

| 不要 | 因为它 |
|------|--------|
| 在内容区用紫色渐变背景 | 破坏 Nothing Light 的干净调性 |
| 给卡片加圆角和阴影 | 不是这个风格 |
| 用弹窗/模态框打断学习流程 | 破坏沉浸感 |
| 用过于复杂的图表 | 学习者不是来看仪表盘的 |
| 用 emoji 作为主要图标 | 保持一致性，用文字/符号 |
