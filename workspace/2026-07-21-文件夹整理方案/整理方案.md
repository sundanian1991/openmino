## 一、Skills 整理（优先级：高）

### 现状问题

| 目录 | 技能数 | git 跟踪 | 角色 |
|------|--------|---------|------|
| `skills/` | 41 | 0 | 全部被 gitignore，**实际不入库** |
| `.codex/skills/` | 4 | 5 文件 | AGENTS.md 声明的主力目录，但只有 4 个 |
| `.agents/skills/` | 38 | 0 | 全部被 gitignore |
| `.claude/skills/` | 135 | 129 文件 | 实际主力，git 跟踪最多 |
| 系统可用 | 210 | — | 4 处汇总去重后 |

**核心问题**：
1. **4 处目录职责不清**：AGENTS.md 说 `skillsDir: ./.codex/skills`，但实际主力是 `.claude/skills/`
2. **根 `skills/` 名存实亡**：41 个全部被 gitignore，git 里一个文件都没有
3. **命名不一致导致加载失败**：根 `skills/` 里 8 个技能命名和系统列表不匹配
   - `grill-me-skill` → 系统是 `grill-me`
   - `luban-skill` → 系统是 `luban`
   - `addsum-slide-maker`、`museum-magnet-card-designer`、`zhongguose-ppt-skill`、`generative-tool-bycoraldesign` → 系统列表里根本没出现，可能已废弃或从未加载成功
4. **大量重复存储**：同一技能在多个目录都有副本，浪费空间且版本难统一

### 整理方案

**目标**：统一到单一目录 `.codex/skills/`（与 AGENTS.md 声明一致），其余 3 处清理。

**步骤**：

```
1. 确认主力目录：.codex/skills/（AGENTS.md 已声明）
2. 合并去重：
   - .claude/skills/ 的 135 个 → 对比 .codex/skills/ 已有的，增量迁入
   - .agents/skills/ 的 38 个 → 同上
   - skills/ 的 41 个 → 同上（注意命名修正）
3. 命名修正（根 skills/ 里的）：
   - grill-me-skill → grill-me
   - luban-skill → luban
   - 其余 6 个不确定的：逐一打开 SKILL.md 确认是否废弃，废弃则删
4. 清理重复目录：
   - 确认 .codex/skills/ 完整后，删除 skills/、.agents/skills/、.claude/skills/
   - 更新 .gitignore：移除对旧目录的 ignore 规则，确保 .codex/skills/ 正常入库
5. 更新 AGENTS.md：确认 skillsDir 指向 .codex/skills/
```

**风险**：迁移过程中可能丢失技能。**缓解**：先全量备份 `tar -czf /tmp/skills-backup.tar.gz skills/ .codex/skills/ .agents/skills/ .claude/skills/`，迁移后逐一验证系统可用技能数 ≥ 210。
