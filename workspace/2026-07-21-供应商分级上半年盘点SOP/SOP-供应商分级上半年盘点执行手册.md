### 2.2 数据 1：月度赛马评分

**取数规则**：
- 从赛马系统按"金条产线 + 月份"筛选
- 时间范围：2026-01、02、03、04、05、06 共 6 个月
- 字段：供应商ID、供应商名称、月份、**首贷分（0-100）、复贷分（0-100）**
- 每家供应商每月有 2 条分数记录（首贷 + 复贷）

**⚠️ 首贷/复贷处理规则**：

系统输出两个独立分数，需要合并为一个"月度赛马分"：

```
月度赛马分 = (首贷分 + 复贷分) / 2
```

**偏科标记**（用于报告呈现，不影响分数计算）：

| 条件 | 标记 | 含义 |
|------|------|------|
| \|首贷分 - 复贷分\| ≤ 10 | ⚖️ 均衡 | 首贷复贷能力均衡 |
| 首贷分 - 复贷分 > 10 | ↗️ 首贷偏强 | 首贷能力明显强于复贷 |
| 复贷分 - 首贷分 > 10 | ↘️ 复贷偏强 | 复贷能力明显强于首贷 |

> 💡 **为什么用算术平均而不是按体量加权？**
> 1. 本次为首次盘点，按体量加权需要额外取历史体量数据，增加取数复杂度
> 2. 算术平均简单透明，管理层容易理解
> 3. 偏科标记已能反映结构问题，后续常规盘点可考虑升级为按体量加权

**Q2 赛马基础分计算**：
```
Q2赛马基础分 = (4月赛马 + 5月赛马 + 6月赛马) / 3
            = [(4月首贷+4月复贷)/2 + (5月首贷+5月复贷)/2 + (6月首贷+6月复贷)/2] / 3
```
（保留 1 位小数）

**异常处理**：
- 某月缺失 → 当月按 0 分计入，并在报告中标注
- 供应商入项不足 3 个月 → 本次为"数据不全"，不参与评级，单独列入"观察区"

#### 🔑 回填方式：默认B档 + 只报异常（简化版）

> **核心思路**：先全部预填为 B 档（0分），同事只需标记异常月份，大幅降低回填负担。

**Step 1 - 预填默认值**：在 Excel/飞书表格中，将 11家×3个月×4项 = 132 个格子全部预填为 **B**（0分）

**Step 2 - 发给同事**：只说一句话：
> "下表已默认全部正常（B档）。如果某月这家有异常（人员大量流失、产能暴跌>20%、SLA<85%、突发事故），请把对应格子改成 A（表现突出）或 C（出现问题）。没异常不用动。"

**Step 3 - 回收确认**：同事改完后，检查：
- 每个 A/C 是否有事实依据支撑
- 无依据的 A/C 强制退回为 B

**同事实际负担**：从"理解4套标准+做144个判断" → 改成"扫一眼，有异常改几个格子"

**Excel 实现**：在模板中预填 B，设置 A/B/C 下拉选项，同事只需改异常格子。

## 三、评分计算（公式 + 示例）

### 3.1 最终得分公式（PDF 第五条）

```
最终得分 = Q2赛马基础分 - Q2合规扣分 + Q2稳定性得分 + Q2供管自评加分
```

**满分上限**：100 + 4 + 5 = **109 分**（赛马基础分上限100）
**下限**：无下限（合规扣分可累计）

### 3.2 计算示例（3 个典型场景，含首贷/复贷完整链路）

#### 示例 A：优秀供应商（均衡型）

**Step 1：月度赛马分计算（首贷+复贷→算术平均）**

| 月份 | 首贷分 | 复贷分 | 月度赛马分 |
|------|--------|--------|-----------|
| 1月 | 92 | 90 | (92+90)/2 = **91.0** |
| 2月 | 94 | 92 | (94+92)/2 = **93.0** |
| 3月 | 90 | 88 | (90+88)/2 = **89.0** |
| 4月 | 93 | 91 | (93+91)/2 = **92.0** |
| 5月 | 95 | 93 | (95+93)/2 = **94.0** |
| 6月 | 91 | 89 | (91+89)/2 = **90.0** |

**Step 2：Q1/Q2 赛马基础分**

```
Q1赛马基础分 = (91.0 + 93.0 + 89.0) / 3 = 91.0
Q2赛马基础分 = (92.0 + 94.0 + 90.0) / 3 = 92.0
```

**Step 3：偏科标记**

```
Q2首贷均分 = (93+95+91)/3 = 93.0
Q2复贷均分 = (91+93+89)/3 = 91.0
分差 = 93.0 - 91.0 = 2分 ≤ 10 → ⚖️ 均衡
```

**Step 4：最终得分**

| 项 | 数值 | 说明 |
|----|------|------|
| Q2 赛马基础分 | 92.0 | (92+94+90)/3 |
| Q2 合规扣分 | -5 | 1次黄牌 |
| Q2 稳定性得分 | +3 | 3A1B（人员无变动、产能稳定、SLA≥95%、无突发） |
| Q2 供管自评加分 | +4 | 战略协作/响应质量/高效执行/共同成长 4项"高" |
| **最终得分** | **94.0** | 92-5+3+4 |

**Step 5：九宫格与评级**

```
环比% = (92.0 - 91.0) / 91.0 × 100 = +1.1% → Y档"持平"
X档 = 按排名（假设排第2名）→ "高"
九宫格 = 高-持平 → [H2]核心保持
评级 = A（X=高，Y=非下降）
```

```

W2 = IF(ABS(P2-R2)<=10, "⚖️均衡", IF(P2-R2>10, "↗️首贷偏强", "↘️复贷偏强"))  ← 偏科标记
```

```
G2 = C2 - D2 + E2 + F2                    # 最终得分
H2 = RANK(G2, $G$2:$G$13, 0)               # 排名（降序）
I2 = IF(H2<=4, "高", IF(H2<=9, "中", "低"))  # X档（12家专用）
N2 = IF(M2="高", IF(K2="下降", "A(防下滑)", "A"), IF(M2="中", "B", IF(M2="低", "C", "")))  # ABC评级
```

## 四、九宫格映射 + ABC 评级 + 三张清单

### 4.1 X 轴分位切分（11 家专用规则）

**标准切分**（PDF 第九条）：
- 高贡献：前 30%（即前 11×30% = **3.3 家 → 取 3 家**）
- 中贡献：30%-70%（即 **5 家**）
- 低贡献：后 30%（即 **3 家**）

**11 家的特殊规则**（小样本必须执行）：
1. 先按最终得分降序排列
2. 第 1-3 名 → X 档"高"
3. 第 4-8 名 → X 档"中"
4. 第 9-11 名 → X 档"低"
5. **临界点人工复核**：
   - 第 3 名 vs 第 4 名分差 < 2 分 → 提请管理层判断
   - 第 8 名 vs 第 9 名分差 < 2 分 → 提请管理层判断

### 4.2 Y 轴趋势判定

**趋势计算**：
```
环比% = (Q2赛马基础分 - Q1赛马基础分) / Q1赛马基础分 × 100
```

**Y 档映射**：
| 环比 | Y 档 | 举例（Q1=80） |
|------|------|---------------|
| > +10% | 上升 | Q2 ≥ 88 |
| -10% ~ +10% | 持平 | 72 ≤ Q2 ≤ 88 |
| < -10% | 下降 | Q2 < 72 |

### 4.3 九宫格映射图

```
                  X轴：贡献度
          低贡献(后30%)   中贡献(30-70%)   高贡献(前30%)
上升(>10%)    [L1]培养区      [M1]重点培养     [H1]战略绑定
持平(-10~10%) [L2]观察区      [M2]稳定维持     [H2]核心保持
下降(<-10%)   [L3]预警区      [M3]关注下降     [H3]防止下滑
```

### 4.4 ABC 评级映射规则（PDF 第十条）

九宫格本身不直接等于 ABC，而是结合以下规则：

| 情形 | 评级 | 依据 |
|------|------|------|
| X 档 = 高 且 Y 档非下降 | **A** | PDF第十条"A级：资源优先倾斜" |
| X 档 = 中 | **B** | PDF第十条"B级：维持现状" |
| X 档 = 低 且 Y 档 = 下降 | **C** | PDF第十条"C级：启动整改或清退" |
| X 档 = 低 且 Y 档 = 持平/上升 | **C**（降级观察）| 边缘案例，默认C但可申诉 |
| **触发红线违规** | **直接 C** | PDF第六条 |
| **连续两季 C** | **自动启动解约** | PDF第十一条 |

## 五、集中度管控 + 清退路径判定

### 5.1 集中度管控检查（PDF 第十六条）

**规则**：头部（A级）供应商合计产能占比不超过全局上限 40%（人机模式、纯机除外）。

**执行步骤**：
1. 汇总A级（预计3-4家）供应商的 Q2 月均产能
2. 计算产能占比：A级合计产能 / 金条产线总产能
3. 若 > 40% → **触发预警**，需在报告中说明：
   - 哪家A级占比过高
   - 是否考虑主动培养B级供应商分流
   - 或调整资源分配降低单家依赖

**检查表**：
| 检查项 | 阈值 | 实际值 | 是否达标 |
|--------|------|--------|----------|
| A级合计产能占比 | ≤ 40% | _____ | □达标 □超标 |
| 单家最大产能占比 | 建议≤25% | _____ | □达标 □超标 |

### 5.2 清退触发条件判定（PDF 第十一条）

对每家 C 级供应商，按以下顺序判断：

```
触发条件1：当季触发红线违规？
    ├─ 是 → 路径三（红线清退）
    └─ 否 ↓

触发条件2：连续两个季度评级为C？
    ├─ 是 → 自动启动解约流程（路径一，已到末期）
    └─ 否 ↓ （本次为首次盘点，无连续季度数据，跳过此条）

触发条件3：当季评级为C 且 趋势下降？
    ├─ 是 → 路径二（快车道清退，30天内完成交接）
    └─ 否 ↓

触发条件4：首次C，趋势持平/上升
    └─ 路径一（常规清退：整改30天→观察→复评→解约）
```

### 5.3 三条清退路径（PDF 第十二条）

**路径一：常规清退**（首次C，趋势持平/上升）
- 整改期 30 天 → 出具整改报告
- 观察期 1 个季度
- 复评：达标 → 升回 B；未达标 → 解约
- 关键节点：D30 整改报告、D90 复评决策

**路径二：快车道清退**（当季C且趋势下降）
- 通知供应商（书面）
- 30 天内完成业务交接
- 关键节点：D0 通知、D30 交接完成

**路径三：红线清退**（触发红线违规）
- 联合评估（供管 + 业务 + 法务）
- 管理层决策
- 执行交接（时间视违规严重程度）

### 5.4 清退前必须确认（PDF 第十三条）

**清退前 1 个月必须确定替代供应商**，否则暂缓清退。

**替代供应商检查清单**：
- [ ] 储备库中有可承接的潜在供应商
- [ ] 替代供应商已完成入项评估
- [ ] 产能、SLA、价格可承接原业务量
- [ ] 交接方案已制定
