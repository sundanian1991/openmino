# Page List 填写指引

本文件只补充 `SKILL.md` 中不便展开的字段示例和拆分边界。

## 一、页面类型

| 页面类型 | 适用场景 |
|---|---|
| 列表页 | 查询、浏览和管理一组数据 |
| 表单页 | 创建或编辑一条数据 |
| 详情页 | 查看一条数据的完整信息 |
| 仪表盘 | 指标、趋势和全局概览 |
| 看板页 | 按状态、阶段或分组查看任务 |
| 个人页 | 个人资料、设置或个人任务 |
| 登录页 | 登录、身份验证或选择入口 |
| 消息页 | 通知、公告或消息中心 |

弹窗、抽屉、Tab 和页面区块通常不单独编号，在“关键交互”或“页面区块”中说明。

## 二、页面区块写法

“页面布局”填写整体排布类型；“页面区块”只填写区域名称和顺序，不在此列重复填写字段或按钮。

不要只写“基础信息”“相关数据”“数据展示”等抽象词。推荐按以下方式填写：

```text
页面布局：筛选+表格
页面区块：顶部、筛选区、统计区、列表区
主要字段：筛选区：设备类型、运行状态；统计区：设备总数、运行中数量、故障数量；列表区：设备名称、设备编号、设备类型、运行状态、责任人
主要按钮：筛选区：查询、重置；列表区：新增、查看、编辑、删除
```

表单页示例：

```text
基础字段区：设备名称、设备编号、设备类型、规格型号
安装信息区：安装位置、安装日期、责任人
状态区：运行状态、备注
底部操作区：保存、取消
```

## 三、按钮与关键交互

关键交互只写用户可见结果：

```text
新增：打开新增设备抽屉
编辑：跳转 P003 设备编辑
查看：跳转 P004 设备详情
删除：弹窗确认
保存：返回 P001 设备台账
```

不要写接口请求、数据库落库、服务调用等实现细节。

## 四、页面拆分判断

满足以下任一条件时，通常拆成独立页面：

- 有独立菜单或路由入口；
- 用户需要完成独立任务；
- 页面内容结构明显不同；
- 页面有独立的业务状态或操作流程。

以下情况通常不单独拆页：

- 删除确认；
- 简单提示；
- 短表单；
- 页面内 Tab；
- 列表内联编辑；
- 仅展开或收起的内容区。

## 五、最小自检清单

- 页面 ID 唯一；
- 页面名称和所属模块清晰；
- 每个页面有明确目标；
- 页面区块和字段具体；
- 主要按钮有对应交互结果；
- 所有跳转引用的页面 ID 都存在；
- 没有无需求依据的页面。
