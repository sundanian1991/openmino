第一章
三抽屉模型

把任务分成三类，每类对应不同的协同模式：

模式AI 角色人角色典型场景
Automation（自动化）全流程执行验收结果格式转换、日报汇总、翻译
Augmentation（增强协作）提供选项和利弊分析最终决策竞品调研、方案对比
Agent拆步骤 + 调工具 + 执行设边界和约束完整调研报告、代码重构
核心原则
不可逆操作（发送/发布/删除）那段必须人来按，不能全交给 Agent。这是安全的底线。

第三章
三维度判定

三个维度决定任务应该放在哪个抽屉：


① 确定性 — 规则有多清楚？模糊说不清 → 规则明确好验证

② 可逆性 — 做错了能撤吗？不可逆（发送/签订）→ 随时可撤回

③ 任务跨度 — 几步能完？单步即完 → 多步串联任务

判定逻辑
不可逆 → 必须 Augmentation（人决策）。确定性高 + 可逆 → 看跨度：短 → Automation，长 → Agent。跨度大 + 一定程度确定 → Agent。

术语一句话解释
Automation / 自动化AI 按你明确的指令独立完成任务，你只需要验收结果。适合规则清楚、做错能改的任务。
Augmentation / 增强协作人和 AI 一起工作，AI 提供信息和建议，人做最终决策。适合需要判断的任务。
Agent / 智能体AI 自己规划、自己执行多步任务的模式。你只告诉它目标和边界，它自己拆步骤、调工具、完成工作。
3A 分诊法用三个维度（确定性/可逆性/任务跨度）快速判断一个任务该用哪种协同模式。
确定性任务规则有多清楚。规则明确好验证 = 高确定性；模糊说不清 = 低确定性。
可逆性做错了能不能撤回。随时可改 = 高可逆性；发出即生效 = 低可逆性。
任务跨度完成任务需要几步。单步即完 = 短跨度；多步串联 = 长跨度。
