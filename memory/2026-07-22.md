## CLI 身份技巧（关键发现）

- 默认 registered agent 身份：只看自己 claim 的 Issue，unassigned 的看不到（`list` 返回空 ≠ 没创建成功）
- user 身份（owner，看全量）：命令加 `--workspacePath /tmp` 切换
- 管理类（list/complete/close）用 user 身份；执行类（claim/create）用默认 agent
