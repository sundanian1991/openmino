# 2026-08-06 — 供应商冒用京东名义招聘合规事件

## 事件

发现 BOSS直聘「汇讯商务」账号（汇讯（湖北）商务信息咨询有限公司）以京东名义公开招聘，并泄露京东供应商大会视频。随后用供应商站点表准确全称对金条、企业主贷、主贷大额三产线逐一排查，确认**系统性冒用现象**：7 家供应商在公开招聘平台以"京东客服/京东金融客服"名义招聘。

## 交叉核验

21 条链接逐条无头浏览器实测 → **当前有效在招 8 条**（中乾3/翰锐3/毅航1/博岳1）。另 curl 批量检测 19 条主链接 → **18 条 HTTP 200 可访问**（仅毛毛虫-BOSS 404 失效，有 58 链接替代）。BOSS/智联职位详情有 **EdgeOne 人机验证，headless 无法自动通过**，需人工浏览器截图。
