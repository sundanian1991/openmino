# 2026-08-06 — 供应商冒用京东名义招聘合规事件

## 事件

发现 BOSS直聘「汇讯商务」账号（汇讯（湖北）商务信息咨询有限公司）以京东名义公开招聘，并泄露京东供应商大会视频。随后用供应商站点表准确全称对金条、企业主贷、主贷大额三产线逐一排查，确认**系统性冒用现象**：7 家供应商在公开招聘平台以"京东客服/京东金融客服"名义招聘。

## 确认违规供应商（7家）

| 供应商 | 特殊违规 |
|---|---|
| 汇讯（湖北）商务信息咨询 | 泄露供应商大会视频+供应商名单；站点超限（6职场 > 上限4） |
| 合肥毅航通信（+母公司广州毅航） | 泄露京东数科财富项目数据（50人力/top工资8W+/人均1w+） |
| 曲靖翰锐信息技术 | 去才职位已截图实锤 |
| 毛毛虫（昆山）商务咨询 | 当前有效链接已失效（BOSS 404） |
| 河北博岳通信技术股份 | 电商客服类（京东店铺/在线打字客服） |
| 陕西海腾信息科技 | 电商客服类 |
| 中乾（深圳）投资控股 | 3 条当前有效职位（猎聘+BOSS） |
