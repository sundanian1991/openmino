年老师在做一套人机协同的教学产品，目标是让职场人学会用AI协同工作。

### 你的课程结构（human-ai-collaboration-guide.html）

```
01 自测定位：你在哪一阶？（4阶能力模型）
02 工作×AI地图：11个工作模块×1249条记录数据
03 本质：协同的本质是什么（四层模型：任务→判断→知识→进化）
04 3A分诊法：30秒决定怎么分（Auto/Augmentation/Agent）
05 演进：从Tool到Agent的五阶段
06 方法：三个层次（L1日常AGENTS.md / L2标准PMP五阶段 / L3长周期三大锚点+七步工作流）
07 验证：40万次Claude Code对话数据 + 四维评估
08 练习：四阶梯能力培养路径
```

### Vibe OS结构（learn.html）

```
L1 执行层：Vibe 6步流水线（idea→交互→架构→设计→原型→实现）
L2 编排层：里程碑+roadmap + dashboard共驾 + 验证门禁
L3 接力层：人下发PROMPT.md → AI夜间执行 → DONE.md回传
```

交互模式：左侧SVG架构图（可点击）+ 右侧故事面板（展开真实案例）

## 优化方案 v2（2026-07-29）

### 核心改造

从"展示型文档"到"交互式方法中心"：

```
首页：Hero + 30秒自测（你在哪一阶？）
  ↓
核心：三层方法地图（交互式，左侧架构图+右侧面板）
  ├─ L1 日常层：AGENTS.md
  │   └─ 点击展开：5条规则 + 正误对比 + 可下载模板
  ├─ L2 标准层：PMP五阶段
  │   └─ 点击展开：每步真实案例 + PROJ.md/PLAN.md模板
  └─ L3 长周期：三大锚点+七步工作流
      └─ 点击展开：Vibe OS真实故事 + orchestrate技能包
  ↓
判断档案：5问提取法（交互式练习）
  ↓
验证：四维评估 + 40万次对话数据
  ↓
资源包：可下载技能包（task-handoff模板、AGENTS.md模板）
```

### 关键改造点

| 改造 | 做法 | 理由 |
|------|------|------|
| 加导航锚点 | 顶部固定导航，每章有进度标记 | 读者知道"我在哪" |
| 加真实案例 | 每个方法节点配一个"某人用这套方法解决了X问题"的故事 | 从"知道"到"会用" |
| 加可复制prompt | 每个方法配"复制启动prompt"按钮 | 降低行动门槛 |
| 加交互式练习 | 判断档案5问法做成表单，用户填完自动生成 | 从"看"到"做" |
| 加技能包下载 | task-handoff、orchestrate、AGENTS.md模板 | 拿走就能用 |

### 可复用技能

| 技能 | 用途 |
|------|------|
| task-handoff | L3层的PROMPT.md/DONE.md模板生成 |
| orchestrate | L3层的里程碑编排示例 |
