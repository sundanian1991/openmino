## CLI 操作技巧（关键）

**身份切换**（重要）：
- 默认 registered agent 身份：只能 list/view 自己 claim 的 Issue，unassigned 的看不到（`list` 返回空不是没创建成功）
- user 身份（owner，看全量）：命令加 `--workspacePath /tmp` 即切到 user
- **管理类操作（list/complete/close）用 user 身份；执行类（claim/create）用默认 agent 身份**

**已知 CLI 能力边界**：
- `space goal list` 只读，无 `space goal create/update/delete`（目标树只能在 UI 建）
- `space issue create/list/view/update/claim/complete/close/comment` 均可用
- `--body-file` 必须用 workspace 内相对路径，不能用 /tmp 绝对路径

## 分级盘点SOP进展（2026-07-29）

**模板文件**：`workspace/2026-07-21-供应商分级上半年盘点SOP/供应商分级盘点-计算模板.xlsx`

**结构**（9个Sheet）：
1. 赛马分原始数据：11家×6月首贷/复贷分 + Q1/Q2均分/基础分/环比/Y档/偏科公式
2. SLA扣分台账：黄牌/舆情投诉/红线（下拉选择），自动算合规扣分
3. 稳定性检查表：Q2三个月×4项，默认B档，有异常改A/C
4. 供管自评表：5项高/中/低，自动算加分
5. **评级结果**：左区=首贷评级 / 右区=复贷评级（独立排名、九宫格、ABC）
6. 三张清单：左右分区，INDEX+SMALL+IF抓取A/B/C级
7. 集中度管控：A级产能占比检查
8. 清退路径：首贷/复贷分别判定

**关键设计决策**：
- 首贷和复贷**分开评级**（老板要求："首贷有问题就首贷做管理"）
- 所有计算列用Excel公式，不能写死数值
- 月度赛马分 = (首贷分 + 复贷分) / 2（首次盘点用算术平均，后续可升级为体量加权）

**赛马数据关键发现**（2026-07-29）：
- 首贷：毅航合肥稳居第1（6月全第一）；翰锐波动最大（2月第2→3月第9→5月第3）
- 复贷：无绝对统治者，排名每月剧烈波动；华啸从1月第9逆袭到6月第1
- 岐力/华啸3月才加入首贷赛马

**目标**：减少首尾差，针对性辅导职场，强化资源投入，规范管理动作

**机制要点**：
- 适用：金条产线（含首贷/复贷），有业务评级的MOB6+评级C坐席
- 触发：不定期，服务组依据首尾差异申请启动（非自动）
- 分级处置：尾部数据回收清退 + 中段专项改善辅导
