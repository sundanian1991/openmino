# 2026-08-17

## MiMo UltraSpeed 模型配置问题排查

### 背景

收到小米 MiMo 邮件，已开通 MiMo-V2.5-Pro-UltraSpeed 体验权限。用户在 MyAgents 中配置该模型，但报错"找不到模型"。

### 排查过程

1. **检查 MyAgents 配置**：`xiaomi-mimo-token-plan` provider 已配置 `mimo-v2.5-pro-ultraspeed`，状态 valid
2. **测试 API 调用**：返回 `400 not supported model mimo-v2.5-pro-ultraspeed`
3. **列出可用模型**：通过 OpenAI 兼容接口查询 `token-plan-cn.xiaomimimo.com`，返回的模型列表中**没有 UltraSpeed**
4. **搜索官方信息**：发现 MiMo 有两种计费模式：
   - Token Plan（预付费套餐）：`token-plan-cn.xiaomimimo.com` 或 `token-plan-ams.xiaomimimo.com`
   - API 模式（按量付费）：`api.xiaomimimo.com/v1`
5. **GitHub issue #851 确认**：明确写着 "Ultraspeed requires API billing"

### 结论

**UltraSpeed 只支持 API 模式（按量付费），不支持 Token Plan（预付费套餐）**

用户当前用的是 Token Plan 的 key（`tp-` 开头），所以无法调用 UltraSpeed。

### 解决方案

1. 去 [platform.xiaomimimo.com](https://platform.xiaomimimo.com) 登录
2. 找到"API 密钥"或"开发者中心"
3. 创建新的 API Key（应该以 `sk-` 开头）
4. 在 MyAgents 中新建自定义 provider：
   ```bash
   myagents model add \
     --id xiaomi-mimo-api \
     --name "小米 MiMo API" \
     --base-url "https://api.xiaomimimo.com/v1" \
     --models mimo-v2.5-pro-ultraspeed \
     --model-names "MiMo UltraSpeed" \
     --primary-model mimo-v2.5-pro-ultraspeed \
     --auth-type api_key \
     --protocol openai
   ```
5. 用新创建的 API Key 配置这个 provider

### 状态

待用户去平台创建 API Key 后继续配置。
