- 重构 TrainMode、DialogueMode、DocMode、MeetingMode 使用 PageContainer
- 解决了 CSP 阻止 Vite HMR WebSocket 的问题（在 index.html 的 CSP 中添加 `ws://localhost:*`）

**Phase 20: 样式规范化**
- 创建 LoadingSpinner 组件（支持 spinner/dots/pulse 三种变体）

**Phase 22: 视觉升级**
- 创建 animations.css 动画系统
- 优化卡片阴影、圆角、hover 效果
- 添加微交互动画（bounce-in、shake 等）

**Phase 23: 体验优化**
- 创建 Skeleton 组件（支持 text/card/list/avatar 四种变体）
- 完善键盘导航和可访问性

### 关键决策

1. **PageContainer 设计**：支持 3 种变体（default/recording/centered），统一所有模式的布局结构
2. **动画系统**：集中管理所有过渡动画，确保一致性和性能
3. **组件库**：创建可复用的组件库，提升开发效率

### 遇到的问题

1. **CSP 阻止 HMR**：dev 模式下白屏，原因是 CSP 阻止了 Vite HMR WebSocket。修复方法：在 index.html 的 CSP 中添加 `ws://localhost:*`。
2. **TypeScript 编译错误**：TopBar 没有导出 TopBarProps。修复方法：在 PageContainer 中单独导入类型。
3. **CSS @import 顺序**：@import 必须在其他语句之前。修复方法：调整 globals.css 中的 @import 顺序。

### 商业化 UI 优化方向

用户追问"现在的 UI 是否达到商业化水准"，我诚实评估：
- **当前优点**：布局清晰、颜色系统一致、有设计感的字体
- **当前不足**：视觉精致度不够、微交互缺失、品牌感弱、细节处理粗糙

**待优化**：
1. 视觉精细化：卡片阴影、圆角、边框需要更细腻
2. 微交互：hover效果、点击反馈不够丰富
3. 品牌感：缺少独特的品牌视觉元素（logo、品牌色）
4. 细节处理：文字大小、行高、字间距需要调整
5. 可访问性：键盘导航、颜色对比度需要完善
