## 关键教训

1. **pipx + Homebrew Python**：CLI 工具用 pipx 不用 pip3（PEP 668）；pipx 隔离环境缺依赖用 `pipx inject`，不要 `pip3 install`
2. **微信抓取**：curl/fetch_url.sh 类工具对微信全失效（JS渲染反爬），getnote MCP 后台浏览器渲染是可靠替代；getnote 返回 AI 总结非原文
3. **notebooklm 深度分析**：main.py 重复建笔记本，手动复刻 ask 循环可复用已有笔记本；`/tmp` symlink 要用 `/private/tmp`
4. **大整数精度**：getnote note_id 超 2^53，传参取整丢精度，用 list_notes 绕过
